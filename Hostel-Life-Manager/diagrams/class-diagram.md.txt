# UML Class Diagram

## Class Responsibilities

| Class               | Responsibility                          |
| ------------------- | --------------------------------------- |
| `Main`              | Controls the application and user menus |
| `Expense`           | Represents an expense record            |
| `ExpenseManager`    | Manages expense operations              |
| `Meal`              | Represents a meal record                |
| `MealTracker`       | Manages meal records and statistics     |
| `Assignment`        | Represents an assignment                |
| `AssignmentManager` | Manages assignments and deadlines       |
| `Task`              | Represents a daily task                 |
| `TaskManager`       | Manages daily tasks                     |
| `LaundryManager`    | Manages laundry reminders               |
| `FileManager`       | Handles file input/output               |
| `ValidationUtils`   | Validates user input                    |
